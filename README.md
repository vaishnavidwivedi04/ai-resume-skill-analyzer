# AI-Powered Resume Skill Analyzer

An entry-level Data Analyst project that extracts technical skills from resume text,
recommends the best-fit job roles using **TF-IDF + Cosine Similarity**, and performs a
**skill gap analysis** against the recommended role. The project ships with a Jupyter
notebook for analysis and a lightweight Flask REST API for serving predictions.

## Project Overview

Given a resume (raw text), the project answers three questions:
1. Which technical skills does this resume contain?
2. Which job role(s) is this resume the best fit for?
3. What skills are missing to be a stronger fit for that role?

## Objective

Build a simple, end-to-end NLP pipeline — from raw resume text to a job-fit score and
skill gap report — using only classical, interpretable techniques (no deep learning,
no external APIs).

## Dataset

`dataset/Resume.csv` — a collection of 2,000+ resumes, each with:
- `ID` — unique resume identifier
- `Resume_str` — raw resume text
- `Resume_html` — original HTML version (not used in this project)
- `Category` — the job category the resume was sourced from (e.g., HR, Finance, IT)

## Workflow

1. **Load & Explore** — inspect shape, missing values, duplicates, and category counts.
2. **Clean** — lowercase, remove punctuation/numbers, remove stopwords, lemmatize.
3. **EDA** — 8 visualizations covering category distribution, resume length, word
   frequency, and a word cloud.
4. **Skill Extraction** — keyword-match each resume against a list of common technical
   skills (Python, SQL, Excel, Power BI, etc.).
5. **Resume Matching** — TF-IDF vectorize 20 sample job descriptions and the resume,
   then use cosine similarity to recommend the top 3 job roles.
6. **Skill Gap Analysis** — compare the resume's extracted skills against the required
   skills for the top-matched role.
7. **Save Model** — persist the fitted TF-IDF vectorizer and job vectors to `model.pkl`.
8. **Serve via API** — `app.py` loads `model.pkl` and exposes a `/predict` endpoint.

## Technologies Used

- **Python** — pandas, numpy, re
- **NLP** — nltk (stopwords, lemmatization)
- **Visualization** — matplotlib, seaborn, wordcloud
- **Machine Learning** — scikit-learn (TF-IDF, cosine similarity)
- **API** — Flask
- **Model Persistence** — pickle

## How to Run the Notebook

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Launch Jupyter:
   ```bash
   jupyter notebook Resume_Skill_Analyzer.ipynb
   ```
3. Run all cells top to bottom. This will:
   - Clean and explore the dataset
   - Generate the visualizations
   - Extract skills and compute job matches
   - Save `model.pkl` and `job_descriptions.csv`, which `app.py` depends on

## How to Run the Flask API

Make sure `model.pkl` exists (generated by running the notebook first), then:

```bash
python app.py
```

The API will start on `http://127.0.0.1:5000`.

## API Endpoints

### `GET /`
Health check.

**Response:**
```json
{
  "message": "AI Resume Skill Analyzer API Running"
}
```

### `POST /predict`
Analyzes a resume and returns job-fit results.

**Request Body:**
```json
{
  "resume_text": "Python SQL Excel Power BI Pandas Data Analysis Statistics"
}
```

**Response:**
```json
{
  "Top Job": "Data Analyst",
  "Similarity Score": "66.31%",
  "Top 3 Recommendations": ["Data Analyst", "BI Analyst", "Power BI Developer"],
  "Matched Skills": ["data analysis", "excel", "power bi", "python", "sql"],
  "Missing Skills": ["statistics", "tableau"]
}
```

## Sample Request (cURL)

```bash
curl -X POST http://127.0.0.1:5000/predict \
  -H "Content-Type: application/json" \
  -d '{"resume_text": "Experienced in Python SQL Excel Power BI Pandas NumPy Data Analysis and Statistics"}'
```

## Results

- Skill extraction reliably identifies common technical skills (Python, SQL, Excel,
  Power BI, Tableau, Machine Learning, etc.) across resumes from multiple categories.
- TF-IDF + cosine similarity produces sensible top-3 job recommendations that align
  with a resume's dominant skill set.
- The `/predict` endpoint responds in well under 2 seconds for typical resume lengths.

## Future Improvements

- Expand the skill keyword list and job description set for broader coverage.
- Replace keyword-based skill extraction with a trained Named Entity Recognition (NER) model.
- Add a resume-category classification model as a secondary output.
- Support resume file uploads (PDF/DOCX parsing) instead of raw text input.
